# 2-Qubit-SImulation
This project simulates a small quantum computer on a Basys 3, a student FPGA board built around a Xilinx Artix-7 chip. The simulator is a circuit written in Verilog rather than software running on a processor. Pressing a button runs a two-qubit quantum circuit that creates an entangled Bell state, and the board’s 7-segment display shows the result.
